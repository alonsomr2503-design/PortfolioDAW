Buscaminas

Juego del Buscaminas en HTML, CSS y JavaScript (10 columnas x 8 filas, 10 minas).

Cómo jugar: abre codigo_comentado/buscaminas.html en el navegador.

  • Clic izquierdo: destapa una casilla.
  • Clic derecho: pone o quita una bandera.
  • Ganas al destapar todas las casillas sin mina; pierdes si destapas una mina.
  • El botón Nueva partida reinicia el juego.

Ficheros: buscaminas.html (página), buscaminas.js (lógica), buscaminas.css (estilos), buscaminas_imagenes/ (imágenes de las casillas).

buscaminas.js

Buscaminas de 10 columnas x 8 filas con 10 minas. El tablero se dibuja en una tabla HTML (`#tablero`). Reglas implementadas: - Clic izquierdo: destapa una casilla. Si no tiene minas alrededor (valor 0) se destapan en cadena las vecinas. - Clic derecho: pone o quita una bandera (las casillas con bandera no se destapan). - Las minas se colocan en el primer clic, así la primera casilla nunca tiene mina. - Se pierde al destapar una mina (se muestran todas las minas). - Se gana al destapar todas las casillas sin mina. - El botón "Nueva partida" reinicia el juego. Convención de coordenadas: `x` = columna (0..COLUMNAS-1), `y` = fila (0..FILAS-1). Las matrices se indexan como `matriz[x][y]`.
